## 已实测与待补范围

| PTrade 数据能力 | 当前通达信证据 | 兼容边界与下一步 |
| --- | --- | --- |
| `get_price` / `get_history` 日线 | 两只股票、三只 ETF 自 2015 年起历史已验证；匿名初始化有效 | 已恢复按需查询优先级；继续对齐频率、复权、停牌填充、包含结束日及返回形状 |
| 分钟 K 线 | 项目接口已有且健康检查通过 | 核对一分钟时间归属、手/股单位和各频率历史保留范围，不能假定拥有 PTrade 的完整多年分钟历史 |
| `get_snapshot` 基础行情 | 已接入 SmartRouter，实测两只股票和一只 ETF；提供最新价、昨收、开高低、成交额、总量、内外盘及五档，另计算涨跌幅与成交均价 | 数量由手换算为股/份；修正漏返、乱序和跨市场同代码的证券匹配。仅提供确认子集，时间戳、交易状态和涨跌停价等字段不伪造 |

| `get_stock_info` | 财务摘要有上市日、股本、地区、行业等字段，股票列表有名称 | 摘要为最新快照；需要验证股本单位并补真实退市日、证券类别及历史证券池，不能把当前存续股票池用于所有历史日期 |
| F10 公司资料 | 已接入 `get_f10_catalog` / `get_f10_detail`；取得 16 个目录，“最新提示”正文 8,142 字符 | 目录统一返回 DataFrame，正文保留原文；文本不等于结构化财务字段 |
| `get_stock_blocks` | 已修复 SDK 分块下载重叠导致的解析错位，新增 `get_blocks` 获取原始通达信分类 | 三个文件共 48,964 条成员记录，代码全部为有效六位数字，同文件同板块内无重复；仍需对齐 PTrade 的 XBHS 分类与代码，不能直接宣称 `get_stock_blocks` 等价 |
| `get_index_stocks(date)` | 当前板块文件不构成已验证的历史指数成分档案 | 保留现有来源，补充有生效日期的官方成分数据；不能将当前板块成员当作任意历史日期的指数成分 |
| `get_fundamentals` | 最新季度包有 5,576 家公司、659 列；已映射 230 个位置，提供 223 个公开字段（含一个派生字段） | 已贯通解析、DuckDB 与 Parquet；659 列包含未审定字段，不能全部等同于 PTrade 字段，完整查询语义仍需对齐 |
| `get_stock_exrights` | 已有除权数据与项目适配 | 对齐每股分红、配股、送转、股本变更及前后复权系数，不只对齐名称 |
| `get_etf_info` / `get_etf_stock_info` | 新增沪深交易所官方 PCF 源及已确认字段子集，不依赖通达信 | 深市已实测 2020、2026 年指定日期；沪市当前仅最新清单。保留日期、市场和申购/赎回不同现金金额，详见 [PCF 与历史覆盖](ETF_PCF_DATA.md) |

它们是按需读取接口，没有自动归档全部实时行情或重建历史板块；获取及保存示例见

## 当前免费行情通道不能直接补齐的项目

- **Level-2 逐笔委托/成交**：PTrade 明确要求 L2，含毫秒时间、委托/成交编号、
  买卖关联编号、撤单标记和通道号。普通 TDX 分笔接口缺少这些信息，需有授权的 L2 源。
- **ETF 申赎与 PCF 剩余缺口**：已新增交易所来源，但沪市历史、深市连续历史覆盖、
  申赎代码、部分现金字段口径和成分停牌状态仍待补。不能将最新清单用于过去日期，
  指数成分、季度持仓也不能替代每日申赎清单。
- **完整银行/券商/保险财报**：现有 FINVALUE 不足以证明金融行业专用字段完整；
  需补充专门财务报表源，并按 PTrade 表和字段核验。
- **真实账户数据**：资金、持仓、柜台订单、账户成交、券商融券库存与费率
  来自券商/PTrade 交易连接。模拟引擎产生的记录应标为模拟数据。

## 接近一比一需要单独验收的语义

1. **时间可见性**：区分财报期末、公告日、数据修订日；历史查询只使用当时可见版本。
   仅按报告期前填充会产生未来数据风险。
2. **接口返回与参数**：字段名、类型、代码后缀、单位、频率、时区、日期边界、
   默认参数、排序、缺失值、无权限时行为及 pandas/字典形状都需要对照。
3. **历史证券与成分**：区分当前名单、历史成分、生效日期及退市证券，避免幸存者偏差。
   PTrade 自身 `get_stock_blocks` 文档说明返回当前板块；`get_index_stocks` 则支持日期。
4. **不得伪造字段**：缺队列或交易编号时不能用普通成交反推成真实 L2；
   未知财务字段不能统一填零；涨跌停价不能无条件用昨收乘固定百分比。

## 建议实施顺序

1. 已完成可直接确认的财务字段映射；继续核验剩余字段的表口径、单位与历史公告可见性，保留现有批量季度下载路径。
2. 已完成基础快照与五档子集适配；继续补充缺失字段的可信来源。
3. 已修复板块下载和解码；后续对齐 XBHS 分类，并版本化存储证券/行业/成分数据。
4. 已接入历史分笔与分时曲线；继续验证历史保留范围、分钟单位与频率语义，保持与 L2 的能力边界。
5. 已接入官方 PCF 与部分真实历史日期；优先核查连续历史覆盖和缺口，再补金融行业报表及有授权的 L2 源。
6. 用目标 PTrade 版本的真实样本做逐接口、逐字段差异测试；单纯的字段数量不能作为一比一验收标准。

## ETF日线历史覆盖

股票和ETF采用相同的智能补齐原则，普通ETF价格回测不要求PCF。通达信官方历史包为批量来源，目录中遗漏的已上市ETF通过Mootdx分页补充，必要时依次尝试腾讯证券、东方财富未复权日线。具体操作见[网页指南](WEB_DATA_ADMIN.md#etf-选择与回测)。

当前目录不等于历史证券池；有记录和源包日期全部入库也不能证明上市以来无缺口。未上市、募集失败和非独立交易份额按真实生命周期或交易代码处理，不生成上市前价格。沪市目录来自官方分页，深市当前发现依赖通达信目录，完整历史退市名单仍需核验。

本地 `data/ETF_HISTORY_CATALOGUE.csv` 是逐代码覆盖快照，可查看来源、实际日期范围、生命周期、交易代码和核验依据；它不是下载任务历史。数量随更新变化。2026-11-22的一次核验和修正记录见[历史核验报告](archive/reports/ETF_HISTORY_20261122.md)。

## 通达信获取示例

以下接口通过 `SmartRouter` 按需读取，不依赖账户登录。核验日期：2026-11-20。
本页区分 PTrade 的已确认字段子集与通达信原始数据接口，能力边界见本页的接口对照表。

## 快照与五档

```python
from simtradedata.router import SmartRouter

with SmartRouter() as router:
    snapshots = router.get_snapshot(["600519.SS", "000001.SZ", "510300.SS"])
    book = router.get_gear_price("510300.SS")
    books = router.get_gear_price(["600519.SS", "510300.SS"])
```

`get_snapshot` 对字符串和列表都返回按证券代码索引的字典。
`get_gear_price` 对字符串返回单证券的 `bid_grp` / `offer_grp`，对列表返回按证券索引的字典。
两次调用会分别请求实时数据，不保证快照与随后获取的五档来自同一时刻。

| 快照字段 | 来源与单位 |
| --- | --- |
| `last_px`、`preclose_px`、`open_px`、`high_px`、`low_px` | 源报价，元 |
| `business_balance` | 源成交额，元 |
| `business_amount`、`business_amount_in`、`business_amount_out` | 源总量、内盘、外盘，由手 × 100 换算为股/份 |
| `bid_grp`、`offer_grp` | 1–5 档；每档为 `[价格, 股/份数量, 0]`，快照第一档另附空队列 `{}` |
| `px_change_rate` | `(最新价 / 昨收 - 1) × 100`，百分数；昨收大于零时提供 |
| `wavg_px` | 成交额 / 股或份成交量，元；成交量大于零时提供 |

以上单位适用于已核验的沪深股票和 ETF，不作为债券、期货等品种的单位承诺。
原始 `get_realtime_quotes` 保留源数量单位（手），不能把它的 `volume` 与适配快照的股/份数量混用。
证券匹配使用返回的市场和代码，支持漏返、乱序和沪深同代码；每批最多请求 80 个证券。

未提供的字段包括交易状态、涨跌停价、带日期的交易所时间戳、动态市盈率、
完整盘口委买委卖总量及成交笔数等。缺字段不填零；无 L2 委托笔数依照 PTrade 文档为零，队列为空。
零价格的空档保留。没有返回记录时快照为空字典，单证券档位为两个空档位字典；
连接异常仍沿用路由的 `DataSourceError`，调用方应自行处理，不能把通信失败视为合法空行情。

## 当前板块、F10 与历史数据

```python
from simtradedata.router import SmartRouter

with SmartRouter() as router:
    blocks = router.get_blocks("block_zs.dat")
    blocks.to_parquet("tdx-index-blocks.parquet", index=False)

    catalog = router.get_f10_catalog("600000.SS")
    text = router.get_f10_detail("600000.SS", "最新提示")

    trades = router.get_history_transactions("600000.SS", "2026-11-20", start=0, offset=20)
    curve = router.get_history_minutes("600000.SS", "2026-11-20")
    trades.to_parquet("tdx-trades.parquet", index=False)
    curve.to_parquet("tdx-intraday-curve.parquet", index=False)
```

| 数据 | 返回与限制 |
| --- | --- |
| 板块 | DataFrame：`blockname/block_type/code_index/code`；支持 `block.dat`、`block_zs.dat`、`block_fg.dat` |
| F10 目录 | DataFrame；使用实际目录名称获取正文 |
| F10 正文 | 原始字符串，无正文时为 `None`；未自动结构化为财务报表 |
| 历史分笔 | DataFrame：`time/price/vol/buyorsell`；保留通达信原始数量与方向值，分页 `start` 为记录偏移 |
| 历史分时曲线 | DataFrame：`price/vol`；保留源顺序和原始数量，不补造时间戳或分钟 OHLC |

板块下载按服务器实际返回长度推进偏移，避免 SDK 固定步长造成重叠；
解析验证文件长度、记录数、每条六位数字代码和每块最多 400 个代码，异常时拒绝返回。
实测 `block.dat` 为 16,862 条，`block_zs.dat` 为 11,554 条，`block_fg.dat` 为 20,548 条，
全部代码格式有效，同文件同板块内无重复成员。这不证明其与交易所官方成分一致。
板块名称与 `block_type` 为通达信分类，不是 PTrade XBHS 分类；原始文件缺逐成员市场标识，
不要单靠数字代码将所有成员盲目转换成 PTrade 后缀，也不要将当前成员用于任意历史日期。

历史分笔只有 `HH:MM`，方向含通达信值 5；不提供毫秒、成交编号和委托关联编号。
历史分时曲线实测为 240 条。两者都未承诺多年历史覆盖，不替代 PTrade L2 接口或分钟 K 线。
保存样本时应同时记录请求日期、获取时间和板块文件名，便于追溯。

## 自动健康检查

```bash
uv run python -m scripts.check_mootdx_interfaces \
  --interfaces snapshot blocks f10 history_transactions history_minutes \
  --timeout 90 --json-output logs/validation/tdx-extra-data.json
```

这些接口已纳入默认检查列表，每项使用独立进程和超时，单项失败不会隐藏其他结果。
检查验证快照价格及五档、板块代码与重复成员、F10 正文、历史价格和数量。
历史接口请求最近应完成交易日；源返回没有完整交易日期，因此该检查不能证明返回内容的实际日期或历史完整性。
这些检查不会修改生产数据库，也不会自动归档实时行情。
